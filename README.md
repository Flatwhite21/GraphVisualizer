# Сетевой анализ научных авторов (Author Network Analysis)

Приложение для анализа научных связей между авторами и исследователями через соавторство в научных публикациях, переписанное на React 19 + TypeScript + Vite + D3.js.

## Основные возможности

- **Интерактивный D3.js граф связей**: визуализация соавторства с физической симуляцией (force simulation), масштабированием (zoom/pan), перетаскиванием узлов (drag & drop), подсветкой инцидентных ребер и соседей.
- **Метрики центральности**: расчет степени вершин (connections), плотности сети (density), средней степени соавторства, а также нормализованной центральности по посредничеству (Betweenness Centrality по алгоритму Брандеса) и степени центральности (Degree Centrality).
- **Научные школы и кластеризация**: автоматическое разбиение графа на сообщества исследователей (научные школы) с возможностью подсветки и цветовой дифференциации.
- **Каталог публикаций и соавторство**: просмотр, фильтрация и добавление новых публикаций с динамическим пересчетом метрик сети и сохранением в локальном хранилище.
- **Рейтинг исследователей**: сводная таблица всех авторов с ранжированием по публикациям, соавторам и центральности.
