# Анализ научных связей (Scientific Network)

Настольное приложение для анализа научного сотрудничества и соавторства исследователей на основе библиографических данных из Excel (.xlsx).

Разработано в рамках выпускной квалификационной работы (ВКР) бакалавра:
**«Разработка приложения для изучения научных связей между исследователями с помощью сетевых методов»**.

---

## 1. Назначение программы

Программа автоматизирует построение и анализ графа соавторства научных работников (на примере исследователей ПетрГУ и КарНЦ РАН):
1. **Загрузка табличных данных (.xlsx)** с гибким сопоставлением колонок и поддержкой различных разделителей авторов (`;`, `,`, `\n`).
2. **Формирование матрицы смежности** графа соавторства с нулевой диагональю и проверкой симметричности.
3. **Интерактивная визуализация графа**:
   - Все вершины имеют **одинаковый базовый размер**.
   - Все рёбра имеют **одинаковую толщину**.
   - Частота совместных публикаций (вес связи) отображается **исключительно цветом ребра** (последовательный градиент от светло-голубого к тёмно-синему).
4. **Фильтрация и анализ**: по диапазону лет (2000–2026 гг.), организациям, минимальному числу совместных статей, поиск эго-сети конкретного исследователя.
5. **Экспорт результатов**: сохранение матрицы в XLSX и CSV, списков авторов, таблицы связей, отчета по статистике и изображения графа в высоком разрешении (PNG).

## 2. Используемые библиотеки и стек технологий

- **Python**: 3.11 или 3.12
- **PySide6**: современный графический интерфейс (Qt 6)
- **pandas**: обработка табличных массивов и сведений о публикациях
- **openpyxl**: чтение и запись файлов Excel (.xlsx)
- **NetworkX**: графовые структуры данных, топологические метрики и алгоритм `spring_layout`
- **Matplotlib**: визуализация графа и цветовая шкала
- **pytest**: модульное автоматическое тестирование

## 3. Инструкция по установке и запуску

### Шаг 1. Клонирование или распаковка проекта
Перейдите в директорию `scientific_network`:
```bash
cd scientific_network
```

### Шаг 2. Создание виртуального окружения
Для Windows:
```cmd
python -m venv .venv
.venv\Scripts\activate
```

Для macOS / Linux:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Шаг 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 4. Запуск приложения
```bash
python main.py
```

### Шаг 5. Запуск автоматических тестов
```bash
pytest -v
```

## 4. Формат входного Excel-файла

Приложение принимает файлы `.xlsx` произвольного формата. Пример таблицы представлен в папке `examples/sample_publications.xlsx`:

| Год | Название | Авторы | Организация |
|---|---|---|---|
| 2022 | Цифровые методы в истории | Иванов И.И.; Петров П.П. | ПетрГУ |
| 2023 | Анализ научных связей | Иванов И.И.; Сидоров А.А. | ПетрГУ |
| 2024 | Методы цифровой гуманитаристики | Иванов И.И.; Петров П.П. | ПетрГУ |
| 2024 | Исторические базы данных | Петров П.П.; Сидоров А.А. | КарНЦ РАН |
| 2026 | Интеллектуальный анализ графов | Иванов И.И.; Петров П.П.; Васильев В.В. | ПетрГУ |

### Особенности обработки авторов:
- Поддерживаются разделители: `;`, `,`, перенос строки `\n`.
- Безопасная эвристика: если в строке есть точка с запятой, разбор ведется по ней, что предотвращает ошибочное разделение формата `Фамилия, Инициалы`.
- Автоматически удаляются лишние пробелы и дубликаты автора внутри одной публикации.
- Публикации одного автора не создают петлю (петли исключены).

## 5. Алгоритм построения матрицы смежности

Матрица смежности $A$ формируется для всех уникальных авторов $\{v_1, \dots, v_n\}$:
1. Значение элемента $A[i, j]$ равно количеству совместных публикаций авторов $i$ и $j$.
2. Главная диагональ строго равна нулю: $A[i, i] = 0$.
3. Матрица симметрична: $A[i, j] = A[j, i]$.
4. Авторы без соавторов также присутствуют в матрице (со строкой и столбцом из нулей).

## 6. Принцип визуализации (Требование диплома)

В соответствии с требованиями научного исследования:
1. **Размер узлов**: константа (все кружки одинакового диаметра).
2. **Толщина линий**: константа (фиксированная ширина линий $2.2\text{px}$).
3. **Цвет линий**: отражает число совместных публикаций:
   - 1 статья: светло-голубой (`#93c5fd`);
   - 2 статьи: насыщенный синий (`#3b82f6`);
   - 3 статьи: глубокий кобальтовый (`#1d4ed8`);
   - 4+ статей: тёмно-синий / индиго (`#1e3a8a` / `#0f172a`).
Справа от графа отображается цветовая легенда (`Colorbar`).

## 7. Экспорт результатов

По нажатию кнопки **«Экспорт результатов»** программа сохраняет в выбранную папку 6 файлов:
1. `матрица_смежности.xlsx`
2. `матрица_смежности.csv`
3. `список_исследователей.xlsx` (с числом статей и соавторов)
4. `таблица_связей_соавторства.xlsx` (пары соавторов и вес связи)
5. `статистика_сети.xlsx`
6. `граф_соавторства.png` (изображение 300 DPI)

## 9. Известные ограничения

- При очень больших объемах графа (свыше 3000 исследователей) алгоритм `spring_layout` может требовать нескольких секунд для позиционирования. Рекомендуется использовать фильтр по минимальному весу связи или годам.
- При наличии полных омонимов в разных институтах требуется предварительная проверка аффилиации.
